# Documentação do projeto — Biblioteca Fácil

Esta pasta reúne os registros do Product Owner e as documentações individuais dos cinco integrantes.

## Estrutura
- `documentacao-po/`: visão do produto, requisitos, atuação do PO, arquitetura, desafios, roteiro de fala e perguntas da banca.
- `documentacao-integrantes/`: modelo individual para cada integrante e controle de preenchimento.

## Cuidados para a entrega
- Completar nomes, datas e responsabilidades que ainda estejam indicados como campos.
- Cada integrante deve revisar e validar seu próprio documento.
- Não apresentar mocks como persistência real nem afirmar integração Angular–API sem evidência.
- Manter as descrições coerentes com o código e com o trabalho efetivamente realizado.
