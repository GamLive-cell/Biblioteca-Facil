# Documentação individual dos integrantes — Biblioteca Fácil

Esta pasta contém um modelo individual para cada uma das cinco pessoas do Grupo 2.

## Como preencher
1. Cada integrante deve preencher somente a sua própria pasta.
2. Substituir os campos entre `[colchetes]` por informações verdadeiras.
3. Descrever apenas atividades que realmente realizou.
4. Incluir caminhos de arquivos, commits, telas ou testes como evidências quando possível.
5. Não afirmar que uma funcionalidade está integrada ou concluída sem conseguir demonstrá-la.
