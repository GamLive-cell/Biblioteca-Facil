## 4. Relação com o sistema

## Contexto do projeto

O Biblioteca Fácil é um sistema web acadêmico desenvolvido para apoiar a rotina de uma biblioteca. A proposta contempla o gerenciamento de livros e usuários, o acompanhamento de empréstimos e devoluções e a consulta das informações por meio de uma interface web.

A solução foi organizada em duas partes principais:
- **Frontend:** aplicação Angular, responsável pelas telas e pela interação com o usuário.
- **Backend:** API desenvolvida com NestJS, organizada em módulos e preparada para persistência com MongoDB por meio do Mongoose.

**Situação técnica registrada na documentação do projeto:** o backend possui estrutura para livros, usuários e empréstimos. O frontend possui telas e fluxos para livros, usuários, empréstimos e devoluções, mas ainda utiliza dados simulados (mocks) em partes da aplicação. Portanto, a integração completa entre Angular e API deve ser tratada como uma etapa de integração/validação, e não como algo concluído sem comprovação.

## 5. Tecnologias e ferramentas relacionadas

Angular no frontend; NestJS na API; MongoDB/Mongoose na camada de persistência prevista para o backend; Git/GitHub para acompanhamento do projeto.
