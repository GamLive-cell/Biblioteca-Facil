# Documentação do Product Owner — Biblioteca Fácil

Esta pasta reúne a documentação da atuação de Product Owner (PO) no projeto integrador Biblioteca Fácil.

## Conteúdo
- `01-visao-do-produto.md`: problema, objetivo, público e escopo.
- `02-atuacao-do-po.md`: responsabilidades, organização e acompanhamento.
- `03-requisitos-e-funcionalidades.md`: funcionalidades identificadas no código e limites do MVP.
- `04-arquitetura-e-decisoes.md`: tecnologias, estrutura e decisões observáveis no repositório.
- `05-desafios-resultados-e-melhorias.md`: desafios, entregas, limitações e próximos passos.
- `06-roteiro-de-fala.md`: roteiro em primeira pessoa para a apresentação.
- `07-perguntas-da-banca.md`: perguntas prováveis e respostas fundamentadas.

> **Nota de transparência:** este material foi elaborado a partir do estado do repositório `develop` enviado em ZIP e do material de orientação da entrega profissional. Onde o repositório não comprova uma informação — por exemplo, nomes de todos os integrantes, datas de cerimônias ou validação com usuários reais — ela não foi inventada. Complete os campos indicados com os dados confirmados pelo grupo.
